# Personal Portfolio Website

This project is a personal portfolio website built with React, TypeScript, and Vite. It is styled with Tailwind CSS and shadcn/ui.

## Prerequisites

- Node.js (v18 or later recommended)
- npm (or a compatible package manager like yarn or pnpm)

## Setup and Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/<your-username>/<your-repo-name>.git
    cd <your-repo-name>
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

## Development

To run the website in a local development environment, use the following command. The site will be available at `http://localhost:5173`.

```sh
npm run dev
```

## Build

To create a production-ready build of the website, run:

```sh
npm run build
```

The optimized static files will be generated in the `dist` directory.

## Preview Production Build

To preview the production build locally, run the following command after building the project:

```sh
npm run preview
```
